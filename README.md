# 이동식 저장장치 관리 프로그램

USB 메모리 · SD 카드 · 외장 HDD를 대장으로 관리하는 Windows용 프로그램입니다.
PC에 연결된 장치 정보를 자동으로 읽어와 등록하고, 등록/수정/삭제로 최신 목록을 유지합니다.

- Python 3.13 표준 라이브러리만 사용 (tkinter + sqlite3), 추가 설치 불필요
- 장치 정보는 WMI(`Win32_DiskDrive`, `MSFT_PhysicalDisk`)를 PowerShell로 조회
- USB 메모리 / SD 카드 / CF 카드 / 외장 HDD를 자동으로 구분

## 실행

```
C:\Python313\python.exe main.py
```

다른 DB 파일을 쓰려면:

```
C:\Python313\python.exe main.py --db D:\backup\usb_list.db
```

데이터는 프로젝트 폴더의 `usb_manager.db`(SQLite)에 저장됩니다.
파일 하나만 복사하면 백업·이전이 끝납니다.

## 화면 구성

| 버튼 | 하는 일 |
| --- | --- |
| 연결 장치 스캔 | 지금 꽂혀 있는 USB/SD 목록을 보여주고, 고른 장치를 정보가 채워진 상태로 등록 |
| 등록 | 장치 없이 직접 입력해 등록 (Ctrl+N) |
| 수정 | 선택 항목 수정 (더블클릭 / Enter) |
| 삭제 | 선택 항목 삭제, 여러 건 동시 선택 가능 (Delete) |
| 장치 재연결 | 이미 등록된 항목에 현재 연결된 장치 정보를 다시 물림 |
| CSV 내보내기 | 현재 목록을 Excel에서 바로 열리는 CSV로 저장 |
| 새로고침 | 목록과 연결 상태 갱신 (F5) |

- 검색창은 관리번호·라벨·종류·담당자·부서·용도·모델·시리얼·파일시스템·비고를 한 번에 훑습니다.
- **종류**와 **상태** 필터를 조합할 수 있습니다. (예: SD카드 + 분실)
- 컬럼 머리글을 누르면 정렬되고, 다시 누르면 역순입니다.
- **자동 감지**를 켜두면 8초마다 연결 상태를 확인합니다. 연결된 항목은 `●` 표시와
  연두색 배경으로 표시되고, 최종연결일이 자동으로 갱신됩니다.
- 상태가 `분실`이면 빨간색, `폐기`면 회색으로 흐리게 표시됩니다.

## 관리 항목

직접 입력하는 항목:

| 항목 | 설명 |
| --- | --- |
| 관리번호 | 자산번호. 중복 불가. 종류에 맞는 접두어로 자동 제안 |
| 라벨/별칭 | 사람이 알아보는 이름 |
| 종류 | USB메모리 / SD카드 / CF카드 / 외장HDD·SSD / 기타. **자동 판별되며 직접 고칠 수 있음** |
| 담당자 / 부서 | 소유·사용 주체 |
| 용도 | 업무용 / 백업 / 자료반출 / 설치·부팅 / 개인용 / 기타 (직접 입력도 가능) |
| 보안등급 | 일반 / 대외비 / 기밀 |
| 상태 | 사용중 / 보관 / 대여중 / 분실 / 폐기 |
| 비고 | 자유 메모 |

관리번호는 종류에 따라 `USB-001`, `SD-001`, `CF-001`, `HDD-001`, `ETC-001` 로 제안됩니다.

장치에서 자동으로 채워지는 항목: 모델, 용량, **파일시스템(NTFS / FAT32 / exFAT 등)**,
시리얼번호, 볼륨 일련번호, 장치 식별자(PNPDeviceID).
파티션이 여러 개면 파일시스템은 `FAT32, NTFS` 처럼 모두 표시됩니다.

날짜는 등록일 · 최종수정일 · 최종연결일이 자동 기록됩니다.

## 종류를 알아보는 방식

USB 카드리더에 꽂힌 SD 카드도 버스 종류는 **USB로 잡히기 때문에**,
버스만 봐서는 USB 메모리와 구분되지 않습니다. 그래서 아래 순서로 판별합니다.

1. `MSFT_PhysicalDisk`의 BusType이 SD(12) / MMC(13) → **SD카드** (노트북 내장 리더)
2. 모델명·장치 식별자를 토큰으로 쪼개 `SD`, `MMC`, `SDHC`, `MicroSD` 등이 있으면 → **SD카드**
   (`CF`, `CFast` 는 **CF카드**)
3. MediaType이 `Fixed hard disk media` → **외장HDD/SSD** (외장 케이스에 담긴 디스크)
4. 그 외 USB 버스이거나 이동식 매체 → **USB메모리**

부분 문자열이 아니라 토큰 단위로 비교하기 때문에 **SanDisk가 SD 카드로 오인되지 않습니다.**
그래도 틀릴 수 있으므로, 등록/수정 폼의 **종류** 항목에서 직접 바꿀 수 있고
직접 고른 값은 이후 자동 판별에 덮어써지지 않습니다.

## 같은 장치인지 알아보는 방식

연결된 장치가 어느 등록 항목인지 판단하는 순서입니다.

1. **볼륨 일련번호**가 같으면 같은 매체로 봅니다.
2. 못 찾으면 **장치 식별자(PNPDeviceID)**로 찾되, 볼륨 일련번호가 기록되지
   않은 항목만 대상으로 합니다.

2단계에 조건을 둔 이유는 카드리더기 때문입니다. 카드리더기는 슬롯마다
장치 식별자가 고정이라, 식별자만 보면 **같은 슬롯에 꽂은 다른 SD 카드**를
같은 카드로 착각합니다. 볼륨 일련번호를 우선으로 두면 카드가 구분됩니다.

대신 **USB를 포맷하면 볼륨 일련번호가 바뀌어** 기존 등록 항목과 연결이 끊깁니다.
이때는 목록에서 해당 항목을 고르고 **장치 재연결**을 눌러 다시 물리면 됩니다.

카드리더기의 빈 슬롯은 목록에 나오지 않습니다.

## 스캔 대상

USB로 연결된 장치, BusType이 USB/SD/MMC인 장치, MediaType이 `Removable Media`인
장치를 모두 훑습니다. 노트북 내장 SD 리더나 외장 HDD도 잡히고,
내장 SATA/NVMe 고정 디스크는 제외됩니다.

## 구조

```
main.py                  실행 진입점
usbmanager/
  models.py              UsbRecord / ScannedDevice, 선택 항목, 종류 판별
  db.py                  SQLite 저장소, 장치 매칭 로직
  scanner.py             PowerShell 호출 + JSON 파싱
  scan.ps1               WMI 조회 스크립트
  util.py                용량·날짜 포맷
  ui/
    app.py               메인 창
    dialogs.py           등록/수정 폼, 연결 장치 선택 창
```

## 제약

- 장치 조회는 Windows에서만 동작합니다 (WMI 사용).
- SD 카드는 리더기를 통해 인식되므로, 카드 자체의 하드웨어 시리얼이 아니라
  볼륨 일련번호로 구분합니다.
